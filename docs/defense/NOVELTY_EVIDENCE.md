# NOVELTY EVIDENCE

## Rule

Never use "first", "novel", or "previously unexplored" without evidence.

Distinguish:
- published fact
- our inference
- provisional gap
- demonstrated contribution

## DARWIN

A near-direct overlap exists:

Fatima T, Lashari TA, Moetesum M, Lashari SA.
PLOS ONE, 2026.
DOI: 10.1371/journal.pone.0361117

It already evaluates:
- repeated nested cross-validation
- eight classifiers
- calibration
- task reduction
- task-selection stability
- cross-validated SHAP

Therefore those components cannot by themselves establish our novelty.

## EEG candidate

Dataset:
OpenNeuro ds004504 / NEMAR on004504.

Existing work already includes:
- conventional EEG feature classification
- functional-connectivity analysis
- deep/hybrid models
- subject-wise validation
- SHAP and explainability
- cross-condition testing in recent work

Therefore our contribution cannot be:
"using EEG to classify Alzheimer's disease."

## Provisional gap

The current candidate is:

A controlled within-participant analysis of how fixed available EEG duration
changes:
1. spectral biomarker estimates,
2. within-subject measurement stability,
3. participant-level classification,
4. uncertainty of the resulting performance estimates.

This gap is PROVISIONAL.

We have not established a first-of-kind claim.

The final novelty statement will be written only after:
- broader literature verification,
- dataset feasibility,
- final protocol definition,
- actual executed results.
