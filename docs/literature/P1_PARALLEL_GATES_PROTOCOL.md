# P1 Parallel Research Feasibility Gates

Date: 2026-11-07
Research stage: Exploratory feasibility

## Research objective

Investigate the feasibility of a publication-oriented
acquisition-aware Alzheimer's EEG methodology.

This is not the final scientific protocol.

## Gate A — Raw EEG acquisition

Download the 88 raw EEG recordings and associated
sidecar files from the pinned NEMAR on004504 v1.0.0
manifest.

Every downloaded file must pass its manifest checksum.

## Gate B — Independent cohort investigation

Check public metadata for candidate external EEG datasets.

Do not download external participant data yet.

No dataset is approved until subject independence,
diagnoses, durations, licensing, and data accessibility
are verified.

## Gate C — Literature verification

Query DOI metadata for directly relevant published work.

Bibliographic verification does not establish novelty.
Methods-level comparison remains required.

## Gate D — Raw EEG feasibility

Inspect all raw EEG files for:

- subject identity
- diagnosis
- sampling rate
- channel count
- recording duration
- initial signal finiteness
- readability

## Scientific restrictions

No final architecture is approved.

No claim of first-ever novelty is permitted.

No clinical usefulness claim is permitted from this
feasibility batch.

No external-validation claim is permitted.

All existing EEG duration experiments remain preserved
as exploratory pilot research.

## Reproducibility

Freeze scripts before execution.

Record execution results.

Verify file hashes.

Keep raw EEG outside Git.

Commit and push only approved audit artifacts.
