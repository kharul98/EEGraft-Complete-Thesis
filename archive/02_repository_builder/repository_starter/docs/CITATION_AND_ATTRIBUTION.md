# Source attribution and citation policy

The canonical repository imports two existing upstream Git histories, rather than claiming everything in this project was newly authored under EEGraft. See each archived source's original README, license (if any), experiment records, and cited third-party dependencies. This repository does not grant new reuse rights for external data or weights.

The dataset is OpenNeuro/NEMAR on004504 (DOI 10.82901/nemar.on004504); CBraMod is an externally published pretrained architecture. The custom DSRF decoder was implemented in the later research track. Refer to the final thesis bibliography and verify its detailed metadata before publication.
