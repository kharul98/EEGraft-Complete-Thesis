# 01. Temporal prediction reliability

The early 64-participant study trained standardized class-balanced RBF SVM classifiers on first-minute spectral features and examined their predictions across recording time. Report both changes in labels and stable-but-wrong cases; a constant classifier can be stable without being useful. This is not the later DSRF protocol.
