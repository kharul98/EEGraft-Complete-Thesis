# 04. Frozen CBraMod plus custom DSRF decoder

The custom decoder combines high-level frozen CBraMod token features with low-level temporal convolutional features using learned gating, residual fusion and class-attention pooling. The backbone remains externally pretrained. The later AD/CN cohort has 65 people, with 52 development and 13 locked holdout.
