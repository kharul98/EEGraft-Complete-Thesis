# Figure integration notes

This package contains 13 numbered figures. Four figures were directly restored from user-supplied image files available in the current Library; nine new report graphics were deterministically drawn from repository-reported numeric results. This is **not** a byte-for-byte recovery of the earlier conversation's approved 13-image ZIP, which was not available as an attachment to this turn. 

The report labels restored method graphics as explanatory user-supplied artwork, not new empirical recordings. The duration graphic summarizes an earlier, separate duration analysis. Do not construe plots from reported aggregate figures as raw-EEG reconstructions. Additional authentic raw waveform and PSD plots require the original evidence assets.

Each plot's source text and SHA256 appears in FIGURE_PROVENANCE.json. Code in `source/rebuild_numeric_figures.py` reconstructs the nine numeric graphics. The filenames in `images/` match LaTeX references.
