# Version-safe LaTeX distribution

This folder is copied from the corrected EEGraft Overleaf project and intentionally excludes `main.pdf`, LaTeX auxiliary outputs and all handwritten student signature image files. The `main.tex` macro `\OptionalSignature` is designed to leave whitespace when those images are unavailable. Do not commit or publicly publish scanned signatures.

For signed institutional submission, work in a separate private Overleaf project and upload the relevant images there. Retain the original signed PDF only in private storage. Do not alter author, numerical, or scientific contents merely to make the project public.
