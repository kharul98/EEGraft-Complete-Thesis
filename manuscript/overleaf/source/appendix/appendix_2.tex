\section{Study A Historical Records and Audit Limitations}
Study A's selection statuses are recorded in \path{source/alzheimers-thesis/reports/openneuro_5min_manifest_v2.csv}. Original repeated participant states are in \path{source/alzheimers-thesis/reports/thesis_final/milestone_1a_reliability_v1/subject_repeat_states.csv}. This table contains 230 AD/control and 205 FTD/control participant-repeat rows. The counts are 108 stable-correct, 20 stable-wrong and 102 unstable for AD/control; 109 stable-correct, 27 stable-wrong and 69 unstable for FTD/control. The five-repeat first-minute BAcc means are 73.48\% and 73.72\%, respectively. Repeats do not create new independent subjects.

The archived numeric audit stops at ``AD\_vs\_HC duration rows 1380 != 690.'' The discrepancy is a counting error: its AD file holds 46 people $\times$ 5 repeats $\times$ 3 durations $\times$ 2 models (690 RBF-SVM and 690 logistic-regression rows), without duplicate evaluation keys. The script assumed only one model. Filtering to RBF-SVM restores the expected 690 rows. Direct checks of archived CSVs found no first-minute label disagreements for 230 AD/control and 205 FTD/control SVM evaluations. The original audit still needs a corrected full rerun, and no raw-EEG replay has been verified.

\section{External CAUEEG Evidence and Private-Data Boundary}
The official CAUEEG dataset provider describes the 19-EEG-channel EDF signals, clinical annotation and event JSON, and the patient-overlap-reduced Dementia benchmark at \url{https://github.com/ipis-mjkim/caueeg-dataset} \cite{kim2023caueeg,caueegofficial}. The local research extension reported a frozen primary test in Code 19, event alignment in Code 21, paired condition analysis in Code 22, timing and threshold confound audit in Code 23, age-label audit in Code 24 and incremental age information in Code 25; Code 26 recorded the synthesis. The original files are held on the research computer rather than embedded as individual medical records in the public ZIP.

Primary external results use 57 recordings from the 90-recording CAUEEG test split. The source-to-CAUEEG domain shift includes label scope, acquisition differences and age imbalance, so neither a difference in accuracy nor a change in stability can be attributed to one cause. Original source-trained weights were not retrained during Codes 19--26. The 0.70 threshold and Platt variants are secondary training-selected decisions, not test-chosen hyperparameters.

\section{Figure and Claims Verification Boundary}
The archived source checks establish the original small holdout matrices, five-fold development summaries and historic Study A repeat counts. For CAUEEG, the available inputs to this editorial package are the saved aggregate terminal summaries and figure exports, not the raw protected EDF/test predictions. The publication-safe dataset preview contains no CAUEEG patient signal. The source-independent external pipeline, age-label provenance and restricted permission terms should be verified by the student team before any scientific journal deposit. Exact claims and remaining issues are documented in \texttt{revision\_final/}\mbox{\texttt{EEGraft\_Scientific\_Verification\_Report.md}}.
